    Código Rust de la red

    El archivo se genera a partir del marcado inicial, los pesos y los nombres. Podés editarlo después de descargarlo. Usa la biblioteca estándar de Rust.

    rustc --edition 2021 red_petri.rs
.\red_petri.exe
.\red_petri.exe --explorar
.\red_petri.exe 0 1

    El último comando intenta disparar las transiciones 0 y 1 en ese orden. En Linux o macOS usá ./red_petri.
